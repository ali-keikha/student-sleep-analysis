#  Student Sleep & Mental Health Analysis

A data analysis project that explores the relationship between students' sleep habits, mental health, and academic performance using **Python**, **Pandas**, **NumPy**, and **Matplotlib**.

---

##  Project Overview

The objective of this project is to analyze a dataset of **3,000 students** to identify patterns between sleep behavior and factors such as stress, anxiety, social media usage, exercise, caffeine consumption, and GPA.

The analysis follows a typical Exploratory Data Analysis (EDA) workflow, including data inspection, cleaning, statistical summaries, and answering real-world analytical questions.

##  Example Question

One of the questions explored in this project is:

> **What percentage of male and female students use sleep tracking applications, and how does burnout differ between users and non-users?**

### Findings

* Approximately one-third of both male and female students use sleep tracking applications.
* Burnout was reported more frequently among students who use sleep tracking apps.
* Since this analysis is observational, it does **not** imply a causal relationship. Students experiencing burnout may simply be more likely to use sleep-tracking applications.
